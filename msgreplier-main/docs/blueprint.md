# **App Name**: msgrepeater

## Core Features:

- Platform Selection: Allows the user to select a social media platform (Instagram, WhatsApp, Telegram, X, Facebook) and displays the app logo for each.
- Text Input: An input field where the user can enter the text they want to repeat.
- Character Limit Display: Dynamically displays the selected platform's maximum character limit.
- Live Character Counter: Real-time character count of the generated repeated text.
- Text Generation: Generates the repeated text based on user input and platform character limits.
- Copy to Clipboard: Enables users to copy the generated text to their clipboard.
- Platform optimized repeat logic: Leverage a tool to determine the ideal number of repeats and spacing given the destination platform's particular formatting rules.

## Style Guidelines:

- Primary color: Soft blue (#A0D2EB) for a calm and friendly feel.
- Background color: Light gray (#F5F5F5) for a clean and modern look.
- Accent color: Light purple (#CDB4DB) for interactive elements and highlights.
- Body and headline font: 'PT Sans', a humanist sans-serif for a balance of modern and approachable.
- Use simple, clear icons for each social media platform.
- Mobile-first design with a clear, single-column layout.
- Subtle animations on button hover/click for a delightful user experience.
